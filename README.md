#  Inventory Management App

##  Overview
This project is a Java-based inventory management system that allows users to manage and track items efficiently.

##  Features
- Add new items  
- Update item details  
- Delete items  
- View inventory list  

##  Concepts Used
- Object-Oriented Programming (OOP)  
  - Encapsulation  
  - Inheritance  
  - Polymorphism  

##  Technologies
- Java
